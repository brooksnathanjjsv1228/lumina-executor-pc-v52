## Overview

Lumina Executor is a desktop Roblox script executor for Windows users working with Lua and Luau. Its small interface and integrated script hub provide a single location for arranging, opening, and running scripts.

The application is intended for Roblox scripting workflows on Windows 10 and Windows 11. Auto updating, debugger support, reusable scripts, and multi-instance operation are included for users who want a practical alternative to a larger, more resource-intensive utility.
